# 微光 Pro（M3-01/02）

依据 PRD 第 8 节（2026-11-02 确认）。

## 定价与范围

- 一次买断，StoreKit 非消耗型商品 `dev.weiguang.comic.pro`；国区 ¥20，其他地区取对应档位（美区建议 US$2.99）；开启家人共享。不订阅、无广告、无计时试用。
- 自定义分组永久免费。阅读、全部格式、进度/书签/备份等数据安全功能永久免费。
- 版本节奏：1.0 自动裁白边、应用锁与隐藏系列；1.1 原位阅读、批量整理；1.2 自动翻页、画面滤镜。买断用户后续功能免费获得。
- 至少交付两项 Pro 功能才开放购买（`purchaseOpen`）。功能交付后在 `src/app/proPolicy.ts` 把对应 `delivered` 改为 true。

## 实现

| 位置                                                       | 作用                                                                                                                                                                                                 |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ios/ComicNative/Sources/ComicNative/ProStorePlugin.swift` | StoreKit 2：`status({product})`、`purchase()`、`restore()`，监听 `Transaction.updates` 并发出 `change`。权益来自系统缓存的 `currentEntitlements`，离线可判断；不保存账号或凭证。系统框架，无新依赖。 |
| `src/native/proStore.ts`                                   | 插件类型与注册；浏览器/安卓无插件时 `supportsPro()` 为 false。                                                                                                                                       |
| `src/app/proPolicy.ts`                                     | 纯逻辑：功能清单、开放购买门槛、入口可见性、`requiresPro`/`canPerform`。只有“新增”类操作需要 Pro；关闭、解锁、取消隐藏、读取已有原位书等永远可用（失去权益不丢数据）。                               |
| `src/app/pro.ts`                                           | Pro 状态（signal）：读取、购买、恢复、原生变化订阅；可注入替身测试。                                                                                                                                 |
| `src/components/ProDialog.tsx`                             | 购买页，只在用户从设置点「查看」时出现；列已交付功能与“后续更新，买断用户免费获得”。                                                                                                                 |

入口规则：正式商店在开放购买前不显示「微光 Pro」设置行；Debug 与 TestFlight（沙盒收据）始终显示，并允许“测试环境”购买，用于验证流程。

## 需要在 App Store Connect 完成（用户操作）

1. 签署并生效「付费 App 协议」，填好银行与税务信息。
2. App 内购买项目 → 新建「非消耗型」，产品 ID `dev.weiguang.comic.pro`，参考名称 LumiComic Pro，价格选 ¥20 档，开启家人共享，填写简中/英文显示名称与描述、审核截图（购买页）。
3. 首次提交时把该内购项目与 App 版本一同提交审核（开放购买前不需要）。

## 测试

- 模拟器离线测试：Xcode → Edit Scheme → Run → Options → StoreKit Configuration 选 `ios/App/LumiComicPro.storekit`，即可购买、退款、询问购买（Debug → StoreKit → Manage Transactions）。
- TestFlight：用沙盒 Apple 账户购买/恢复；需要上一节的内购项目已创建。
- 验收要点：购买后设置显示“已解锁”；恢复购买；退款（Manage Transactions → Refund）后回到免费且书架数据不变；家人共享；询问购买显示等待批准。

## 已交付功能

### 批量整理（1.1 第二阶段）

- 书架按当前搜索/筛选多选系列，系列内多选卷；支持全选/取消全选、标记已读/未读、移入分组和从书架移除。只有批量应用需要 Pro，原有逐项整理、单本删除、分组创建/管理继续免费。
- 打开时冻结书目范围，应用前在同一数据库事务里重新核对；导入新增卷或书目被删除时拒绝执行并要求重新选择，避免悄悄扩大删除范围。重叠目标去重，任意写入失败整体回滚。删除先原子生成安全清理任务，事务成功后由原生队列清理；原位只移除书签和缓存，原件不动。
- 分组按系列生效；选择部分卷移动时，同系列其他卷一起移动，操作区始终说明这一点。删除前列出标题、项目数/实际书目数及清除进度/书签的影响，支持取消；删除确认先聚焦取消按钮。书签不因标记未读而删除。
- 无新依赖，无数据库升级，无 Swift 改动；本轮自动检查和实际点检见 DEVELOPMENT_STATUS.md。

### 原位阅读（1.1 第一阶段）

- 添加漫画时可选「导入副本（免费）」或「原位阅读 Pro」。支持与现有导入一致的 ZIP、CBZ、PDF、图片漫画 EPUB；副本导入、单本管理和自定义分组保持免费。原位只新增系统文件书签和页面缓存，不复制漫画本体。
- iOS `ComicReferences.swift` 原生保存 `minimalBookmark`，每次读取先恢复授权、以 `NSFileCoordinator` 协调只读访问，结束后关闭归档句柄并释放 security scope；失效书签可刷新。参照 [Apple 文件访问说明](https://developer.apple.com/documentation/uikit/providing-access-to-directories)。网页只保存 `comic-reference://<UUID>`，不接收外部路径，不保存/导出系统授权数据。
- 记录原件大小、修改时间及格式；原件缺失或变化时，新的原生读取不会直接返回旧缓存。书籍管理与阅读设置可「重新选择原文件」；内容指纹和格式匹配成功才替换授权，书架、页序、进度和书签保留。错误选择保留原授权；读取、重选和移除已有原位书均不要求 Pro。
- 清理失败进入既有重试队列；移除原位书只清缓存和授权，绝不删除/修改原件。授权目录排除整机备份；跨设备不能携带旧授权，需要重新选择原件。复用已有 `books.location/path` 和可选任务字段，不修改已发布数据库结构，无新依赖。
- 使用边界：保留原件，云盘文件先下载；文件提供者撤权、移动/删除或设备重启后的授权失效均可要求重新选择。不能保证所有第三方文件提供者长期可用。真机重启、iCloud/第三方提供者、大文件性能尚待验收，模拟器测试不能替代这些项目。

### 自动裁白边（M3-03）

- 原生 `ContentBounds.swift`：长边 400 灰度分析图 → 外圈判断白/黑底 → 逐行列向内找空白（1% 杂点容忍）→ 留 1% 余量；底色不明、空白页、保留不足一半、每边不到 2% 时不裁。
- `renderPage({ crop: true })`，图片页与 PDF 页均支持，单独缓存。阅读设置按书开关（`books.cropBorders`）；只在 Pro 有效时生效，失去 Pro 后按原图显示且可关闭。
- 验收要点：白边扫描页、黑边扫描页、满版彩页（应不裁）、标题页（应不裁）、条漫与双页观感、翻页耗时。

### 应用锁与隐藏系列（M3-04）

- 原生 `ComicLockPlugin`：`availability`、`authenticate`（deviceOwnerAuthentication）、`setPrivacyCover`、`reveal`。遮挡由 `ComicBridgeViewController` 负责。
- `src/app/appLock.ts`：启动/回到前台上锁；开启需 Pro 与设备密码并验证一次；解锁、关闭不需要 Pro；设备关闭密码时放行并关闭。设置键 `app.lock`。
- 隐藏系列：`series.hidden`；隐藏需 Pro，取消隐藏不需要；设置页可临时显示。
- 验收要点：开启/关闭；冷启动与后台返回各验证一次；多任务界面看不到内容；阅读中切后台再回来位置不变；取消验证停在锁屏可重试；关闭设备密码后能进入；退款后能关闭应用锁、取消隐藏。
