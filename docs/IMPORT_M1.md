# M1 ZIP/CBZ 正式导入

更新：2026-10-30。本轮为 Windows 上的代码准备，尚未经过 Swift 编译与 iOS 真机验收，B1 和性能闸门仍待办。

## 当前可以验证的范围

- iOS 正式书架通过系统文件选择器多选 ZIP/CBZ，按文件逐个导入；仅处理用户自行选择的文件，不加载示例漫画或远端内容。
- 复制、指纹和压缩包读取在原生执行；每次复制至多读取 1 MiB，WebView 只拿文件元数据与作业进度。文件先写入 UUID `.part`，完成后改名为 `.zip`。
- 书籍、自然排序后的图片页目录、作业完成状态使用同一数据库事务保存。过滤隐藏文件、路径越界条目和符号链接；加密包和没有图片的包显示失败，后续文件继续执行。
- 基础指纹去重会跳过已存在的记录，并清理本次多余副本；不会清除原书的进度或原文件。
- 复制和检查阶段可取消；进入原子保存阶段后不再取消。重开时保留已入库书籍，清理未完成副本，要求重新选择中断的文件。清理失败的作业下次打开重试。
- 正式文件位于 Application Support / `ComicLibrary/`，原型位于 `ComicPrototype/`；两者均排除整机备份。原型重置不会删除正式书架。

选择器返回的 `uri` 是当前原生进程持有的临时标识，不是文件 URL。当前不保存跨进程文件授权，也不从中断字节继续复制；重新选择后重新复制。

尚未实现（M1 当时）：系统分享/“用…打开”（iOS 已于 2026-11-12 补上，见下节）、图片文件夹导入、RAR、系列整理、封面网格、正式阅读器和阅读进度。安卓正式原生导入也未实现；没有所需原生插件时导入按钮禁用。

## iOS「用…打开」/分享导入（2026-11-12）

- `Info.plist` 声明 `CFBundleDocumentTypes`：CBZ（`dev.weiguang.comic.cbz`）、ZIP、PDF、EPUB，角色 Viewer、`LSHandlerRank = Alternate`（只进入「用…打开」和分享列表，不抢系统默认打开方式）；`LSSupportsOpeningDocumentsInPlace = NO`，系统先把文件复制到本应用 Inbox。
- `SceneDelegate` 冷启动（`connectionOptions.urlContexts`，先于创建桥接视图）和运行中（`openURLContexts`）都交给 `ComicOpenedFiles`；`ComicImportPlugin.takeOpenedFiles` 换成与文件选择器相同的临时标识，网页 `importOpenedFiles()` 按普通复制导入，重复文件照常识别。标识释放时删除 Inbox 副本；只删本应用沙盒中 `Inbox`/`*-Inbox` 目录里的文件。插件加载时清理上次进程遗留、未导入的 Inbox 副本。
- 收到文件后书架回到首页显示导入记录；正在阅读时不打断。不支持的扩展名不导入，Inbox 副本直接删除。
- 微信、QQ 等 App 通常要先点「用其他应用打开」才会出现完整列表，这是它们的限制。

复制完整工程，安装依赖后构建正式网页并打开已有 iOS 工程：

```sh
pnpm install --frozen-lockfile
pnpm build:ios
pnpm check:ios --release
pnpm exec cap open ios
```

先用 Xcode 编译。`pnpm build:ios` 只做 TypeScript、网页构建与资源同步，不能证明 Swift 编译通过。若要测 M0 性能，改用 `pnpm build:ios:prototype`，按 `IOS_B1.md` 操作；测完正式导入前重新运行 `pnpm build:ios`。

使用 `test-books/` 中自行生成的素材验证以下情况，不使用真实漫画作为自动测试数据：

| 操作                                       | 预期结果                                                               |
| ------------------------------------------ | ---------------------------------------------------------------------- |
| 同时选择两个正常 ZIP/CBZ                   | 逐个复制，书架出现两条记录，页数与过滤后的素材清单一致；退出重开仍保留 |
| 再次选择同一个文件，或其改名副本           | 提示书架中已存在，书架数量不增加，只清理本次副本                       |
| 正常文件夹杂加密包、无图包或损坏目录的 ZIP | 异常项显示失败并清理副本，后续正常文件继续导入                         |
| 复制大包时取消，再取消尚在排队的另一项     | 两项均取消，排队项不开始复制；没有新增书籍或残留 `.part`               |
| 目录检查期间取消                           | 等原生检查返回后停止，不入库，清理副本                                 |
| 复制中强制终止应用，再打开                 | 作业提示中断，临时副本清理；已有书籍和进度保留，重新选择文件可重试     |
| 保存时模拟设备空间不足                     | 没有半条书籍/页目录记录；显示失败，清理失败时保留待清理标记            |
| 先导入正式书籍，再切到 Debug 原型执行重置  | 原型副本删除，正式书籍副本和数据库仍存在                               |

在设备文件容器中确认 `ComicLibrary/` 的文件与目录排除整机备份，同时核查源文件未改变。安装包增量和性能结果按 B1 测量，当前没有实测值。
