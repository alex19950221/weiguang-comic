# 书架与阅读器交互原型

更新：2026-10-30。用于在浏览器里确认界面和操作流程；与正式 App、M0 性能原型分开运行。

## 打开体验

```powershell
pnpm build:prototype
pnpm preview:prototype
```

在这台电脑上打开 [交互原型](http://127.0.0.1:4180/prototype.html)。开发时可改用 `pnpm dev:prototype`，仍访问 `/prototype.html`，支持热更新。

`pnpm dev` 的默认首页仍是 M0 性能原型，`pnpm build:ios` 仍构建正式 App 网页；两者都不是本次交互入口。

## 可以点击什么

| 页面     | 已接上的交互                                                                                                                                                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 书架     | 按系列归组（叠放卡片、系列页）、继续阅读卡片、自建分组与未分组、收藏筛选、阅读状态筛选、搜索书名/文件名、排序、网格/列表、管理弹窗（文件信息、标记读完/未读、移动分组、删除）、导入进度面板、首次打开空书架、最近阅读页；手机底栏为书架/最近/设置，顶栏“+”导入 |
| 阅读器   | 点按左右分区翻页、中间呼出工具栏、首次分区说明、方向键/空格、水平滑动、单页/双页（封面单独、从右向左）/条漫、双击与捏合缩放、页码滑块、章节与缩略图跳页、书签、卷末页与下一卷                                                                                  |
| 阅读设置 | 翻页方向、完整显示/适应宽度、背景、亮度、页面放大、工具栏显示/隐藏                                                                                                                                                                                             |
| 偏好设置 | 跟随系统/暖纸/深色外观、默认阅读方式、双页封面、是否记住阅读位置、原型书架样本（精选 8 本 / 真实文件名 60 本 / 首次打开）、恢复已删除书目                                                                                                                      |
| 导入     | 模拟导入 3 个压缩包（新卷并入系列、重复跳过、加密失败、可取消）；选择或拖入本地 JPG/PNG/WebP 形成图片画册                                                                                                                                                      |

本地图片一次最多12张、每张8 MB以内，逐张在浏览器生成最长边1600像素的预览；不上传、不改原文件。本次添加的本地图片和演示新画册在刷新后移除。内置8本的阅读位置、收藏、书签与设置保存在浏览器本地，下次打开可以继续。

所有封面和分镜都是代码绘制的原创 SVG 视觉样张，不来自真实漫画。它们只出现在独立原型，不随正式 App 打包。ZIP/CBZ 的正式原生导入不在这里模拟处理。

## 代码入口与隔离

- `prototype.html` → `src/prototype-main.tsx` → `src/pages/InteractivePrototype.tsx`。
- `src/reader/DemoReader.tsx`：阅读、翻页、目录和设置入口。
- `src/app/demo.ts`：演示书目、进度、收藏、书签、偏好和本地图片预览；存储键 `weiguang.interactive-prototype.v1`。
- `src/components/DemoArtwork.tsx`、`DemoDialogs.tsx`、`DemoIcon.tsx`：矢量插画、弹窗/设置与图标。
- `src/styles/demo.css`：独立样式与响应式布局。
- Vite 的 `ui-prototype` 模式只构建 `prototype.html`，产物在已忽略的 `prototype-dist/`。正式入口不引用这些演示模块，也不使用演示存储。

## 本轮验证

- `pnpm build:prototype` 通过：TypeScript strict 和独立原型生产构建；无新增依赖。
- `pnpm build:ios`、`pnpm check:ios --release` 通过；检查正式网页与同步资源，未包含交互原型代码、样张或演示存储键。不代表 Swift 编译或真机通过。
- 应用内浏览器实际检查：搜索返回1本、未读筛选返回5本、列表展示8本；取消收藏后收藏列表从3本变2本；添加演示画册和本地图片后书架均从8本变9本。
- 阅读检查：点击/方向键翻页、刷新后页码恢复、书签列表、跳到第10页、双页显示两张、条漫显示12张、反向翻页、页面放大、深色主题、阅读设置均可操作。
- 桌面与390×844手机宽度已查看；手机书架无横向溢出，可见按钮至少44×44px。控制台无错误。
- 检查使用独立的4181端口，不修改用户4180原型中的状态；临时图片通过刷新移除，检查标签页和4181服务已关闭。4180服务保留供用户体验。
- 按工程约定未运行 lint / Vitest；原有22个 Vitest未变。本轮不包含原生文件读取、Swift编译、真机性能或内购验收。
