# M1-05 正式书架

更新：2026-10-30。正式书架已接真实 Dexie 数据与 iOS 原生接口；Swift 编译和真机验收仍未完成，不代表 M1 或闸门验收通过。

## 当前行为

- 系列叠放卡片、系列页与按卷/话排序的书目；封面指向最近在读卷，否则第一本未读完的卷。
- 继续阅读最多三本，读取 `progress` 的真实页码和更新时间。状态、分组、收藏、搜索、排序、网格/列表均作用于真实数据；排序和显示方式持久化到 settings。
- 全部 / 阅读中 / 未读 / 已读完 / 收藏筛选；搜索兼顾系列名、保留的书名和原文件名。书名使用自然排序；最近页只列读过的系列，按阅读时间排序。
- 分组可创建、移动、改名和删除。按系列持久化，删组保留书目；界面显示存储层的中英错误消息。
- 管理弹窗展示原文件名、格式、大小、页数和进度；单本或系列可标记读完/未读、移动分组、删除。读完保存末页，未读清除进度和最近阅读时间，书签保留。
- 导入面板复用 ImportQueue 的等待、复制、检查、保存、成功、重复、失败、取消及中断清理状态；显示复制百分比与大小。清除记录只删完成且没有待清理副本的作业。
- 首次打开显示真实支持的 ZIP/CBZ 导入引导，没有演示入口，也不把尚未实现的文件夹导入或系统分享写成可用。
- 手机底栏为书架 / 最近 / 设置；720 宽为左侧图标栏，桌面为侧栏。外观默认跟随系统，也可明确选浅色/深色；不改变阅读背景设置。新界面文案均走中英 i18n，颜色只用语义 tokens。

M1-05 当轮先以详情承接阅读入口；后续已完成正式阅读器基础接入，单本、系列当前卷和“继续阅读”卡片可直接阅读，管理按钮仍打开详情。最新范围与验收记录见 [READING_M1.md](./READING_M1.md)，下文保留书架当轮的检查结果。

## 封面与删除接口

封面复用 `ComicArchive.thumbnail({bookId,path,entry})`，`entry` 取自然排序后页目录的第一张图片；原生 ImageIO 最长边 400px 降采样，WebView 只接本地缩略图 URL。进入视口附近才请求封面；图片使用 `object-fit: contain` 完整显示横版和长条，读取失败显示格式占位。

新增 `ComicArchive.disposeBook({bookId,deleteCopy})`：

1. 与渲染共用原生串行队列，释放打开的归档并清理该 UUID 的缓存。
2. `deleteCopy=true` 时只按 UUID 拼出固定 `ComicLibrary/` 根目录下的 `.zip / .part` 文件；校验普通文件、符号链接及目录边界。不接收外部路径，不触碰原型副本或用户原文件。
3. `deleteCopy=false` 只清缓存，用于原位文件。目标不存在视为成功，可幂等重试。

IndexedDB 与文件系统无法共用一个事务。`deleteLibraryTarget` 先在同一事务删除书籍、页目录、进度、书签、导入记录、同指纹待匹配备份和已空系列，并写入 `fileCleanup`。事务成功后 `FileCleanupQueue` 调用原生接口；失败保留任务、次数和稳定错误码，书架显示待清理数量，可主动重试，重开 App 也会重试。数据库事务失败不发起文件删除。

没有改动 v1/v2 schema 定义。`library.layout`、`ui.appearance` 是已有 settings 表的新键，不需要数据库结构升级。
